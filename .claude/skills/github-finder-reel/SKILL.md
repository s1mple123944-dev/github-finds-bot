# Ролик «3 находки с GitHub» (Remotion + Whisper)

Канал: Telegram «GitHub Finder». Ролик продвигает канал в TikTok и Reels.

**Сначала загрузи скилл `remotion-best-practices`** (он лежит рядом в `.claude/skills/`) и следуй его роутеру: создание проекта, разметка, субтитры (`remotion-captions`), рендер.

## Входные данные

- **Находки:** 3 последних поста в `sent/*.json` без поля `deleted_at` (или те, что назвал пользователь). Из поста берутся `title` («Имя — что это»), пункты `•` из `text`, строка «Платформы:», звёзды «⭐ …», `media` и `fallback_image`.
- **Сценарий:** `voice/script_*.json` — 5 сегментов `hook`, `1`, `2`, `3`, `cta`. Поле `say` — для озвучки (имена кириллицей: «Ойнк», «ГитХаб»), поле `show` — как писать в субтитрах (Oink, GitHub, Claude).
- **Озвучка:** `gf_hook.wav`, `gf_1.wav`, `gf_2.wav`, `gf_3.wav`, `gf_cta.wav` в `E:\github bot\` (создаются в VoiceStudio голосом «my voice»). Если их нет — напиши сценарий, попроси пользователя озвучить и сохранить файлы с этими именами.

## Шаги

1. **Проект.** Папка `remotion/` в корне репозитория. Если её нет — создай по `remotion-create` (npm). Скопируй озвучку и медиа в `remotion/public/`.
2. **Медиа.** Скачай медиа из постов в `public/`. Не используй картинки, гифки и видео меньше 480×270 (проверь размер) — вместо них `fallback_image` (карточка GitHub). Логотипы и бейджи не брать.
3. **Субтитры.** Транскрибируй каждый wav по `remotion-captions/transcribe-captions.md` (`@remotion/whisper-webgpu`, нужна видеокарта — у пользователя NVIDIA). Сохрани `Caption[]` в JSON по сегменту. Исправь распознанные слова по полю `show` сценария (имена проектов, GitHub, Claude), тайминги не трогай.
4. **Композиция `Top3Reel`**, 1080×1920, 30 fps, длительность считается из длины аудио (`calculateMetadata`). Сцены — отдельные `<Sequence>`: Hook → Find 1 → Find 2 → Find 3 → CTA. В каждой сцене свой `<Audio>` и свои `<BasicCaptions>` (как в `display-captions.md`). Между сценами 0,15 с до голоса и 0,35 с после.
5. **Дизайн (как у канала):**
   - фон `#0D1117` с мягким зелёным свечением сверху, акцент `#3FB950`, текст `#F0F6FC`, вторичный `#8B949E`; шрифт Inter из `fonts/` (Black для заголовков);
   - сверху мелко «GitHub Finder · Telegram» и зелёная полоса прогресса всего ролика;
   - Hook: «3 находки / с GitHub, / о которых / ты не знал» крупно, строки выезжают по очереди;
   - Find: плашка «n / 3», «★ звёзды», имя проекта (Black ~92px), подзаголовок, карточка медиа 920×560 со скруглением 30px (картинка — медленный проезд, gif/видео — без звука), плашка платформ;
   - CTA: «Какая зашла?», «Пиши 1, 2 или 3 в комментах», список трёх находок, зелёная плашка «GitHub Finder», «Сохрани, чтобы не потерять»;
   - субтитры по центру ниже карточки, 2–4 слова, ~66px Black, текущее слово на зелёной плашке;
   - безопасные зоны TikTok: ничего важного в нижних 300px и правых 140px.
6. **Просмотр.** Открой Studio (`npx remotion studio`) и дай пользователю посмотреть.
7. **Рендер.** `npx remotion render Top3Reel out/reel_voice.mp4 --codec h264 --crf 18`, затем выровняй громкость: `ffmpeg -i out/reel_voice.mp4 -c:v copy -af loudnorm=I=-14:TP=-1.5:LRA=11 -c:a aac -b:a 192k out/reel_voice_final.mp4`.
8. **Отправка.** `python reel.py --send-file out/reel_voice_final.mp4 --posts <3 файла из sent/ через запятую>` — бот пришлёт ролик и описание владельцу в личку. Токен берётся из `config.json` или `TG_BOT_TOKEN`; никогда не выводи его в чат.

## Правила роликов

- Первые 1,5–2 секунды решают, пролистнут ли ролик: сразу хук, без вступлений.
- Длина 30–50 секунд. Субтитры обязательны — большинство смотрит без звука.
- Все факты — только из постов (они взяты из README). Не обещать того, чего нет в канале.
- Лицензия Remotion бесплатна для частных лиц и маленьких компаний; если канал станет бизнесом — проверь `remotion-license`.
