# GitHub Finds bot

Claude ищет полезные штуки на GitHub (скиллы, MCP, CLI-утилиты, приложения,
self-hosted) и кладёт готовые посты в `queue/`. Этот бот отправляет их тебе
в Telegram — с видео, гифкой или картинкой и короткой ссылкой.

## Настройка (один раз, 3 минуты)

1. В Telegram открой @BotFather → `/newbot` → получи токен.
2. Дважды кликни `run.bat` и вставь токен, когда бот попросит.
3. Нажми «Start» у своего бота в Telegram — бот сам запомнит chat_id
   и начнёт присылать посты из `queue/` (проверяет раз в минуту).

Хочешь, чтобы посты шли сразу в канал: добавь бота админом канала
(право «Публикация сообщений») и в `config.json` замени `chat_id` на `"@имя_канала"`.

Чтобы бот стартовал вместе с Windows: Win+R → `shell:startup` → положи туда
ярлык на `run.bat`.

## Папки

- `queue/` — посты, которые ждут отправки (их пишет Claude)
- `sent/` — отправленные (по ним Claude понимает, что уже было, и не повторяется)
- `failed/` — не ушло; рядом лежит `.error.txt` с причиной

## Формат поста

```json
{
  "repo": "owner/name",
  "url": "https://github.com/owner/name",
  "title": "Короткое название",
  "text": "HTML-текст поста. {link} — сюда встанет короткая ссылка",
  "media": [{"type": "video|animation|photo", "url": "https://..."}],
  "fallback_image": "https://opengraph.githubassets.com/1/owner/name"
}
```

Бот пробует медиа по порядку; если ни одно не прошло — шлёт картинку-превью
репозитория, а если и она не прошла — просто текст с превью ссылки.
Токен никуда не уходит, кроме api.telegram.org.
